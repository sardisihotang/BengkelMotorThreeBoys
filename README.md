## 📌 Tentang Proyek / About the Project

**[ID]** Proyek ini adalah antarmuka pengguna (User Interface) berbasis web statis yang dirancang khusus sebagai *company profile* untuk layanan bengkel motor. Halaman ini bertujuan untuk mempromosikan layanan servis, menampilkan galeri atau suku cadang, serta memberikan informasi operasional dan kontak yang jelas kepada calon pelanggan.

**[EN]** *This project is a static web-based User Interface designed specifically as a company profile for a motorcycle workshop. The page aims to promote repair services, showcase a gallery or spare parts, and provide clear operational and contact information to potential customers.*

---

## 🚀 Fitur Utama / Key Features

**[ID]**
* **Ikonografi Modern:** Menggunakan library *Boxicons* untuk menghasilkan elemen antarmuka yang tajam, ringan, dan terlihat profesional.
* **Desain Responsif:** Tata letak yang dioptimalkan agar tampilan tetap rapi saat diakses melalui perangkat Desktop, Tablet, maupun Mobile.
* **Struktur Halaman Terpadu:** Memiliki header navigasi yang terstruktur untuk memudahkan pelanggan menemukan informasi layanan dan kontak bengkel.

**[EN]**
* **Modern Iconography:** Utilizes the *Boxicons* library to deliver crisp, lightweight, and professional-looking interface elements.
* **Responsive Design:** Layouts optimized to ensure the interface remains clean and well-proportioned across Desktop, Tablet, and Mobile devices.
* **Unified Page Structure:** Features a structured navigation header to help customers easily find service details and workshop contact information.

---

## 🛠️ Teknologi & Library / Technology & Libraries

* **Struktur & Gaya (Structure & Styling):** HTML5, CSS3 (Vanilla)
* **Interaktivitas (Interactivity):** JavaScript (DOM Manipulation)
* **Ikonografi (Iconography):** Boxicons (v2.1.4)
